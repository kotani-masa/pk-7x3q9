# 対戦で使うAI

| フォルダ | 内容 |
|---|---|
| `core/` | 共通の判断・情報管理 |
| `decks/` | デッキごとの判断。ドラパルト・メガレックウザ・Nのゾロアークex |
| `params/` | 自動調整した数値。ドラパルト・メガレックウザは調整済み、ゾロアークは初期値 |
| `models/` | 学習済みの勝率予測。現在はドラパルト・メガレックウザ用 |
| `data/` | 先読みで仮定する標準デッキリスト |
| `legacy/` | 専用AI未対応のデッキで使う従来CPU |

読み込む順番は `index.html` の末尾にあります。デッキ固有の判断を直す場合は `decks/`、対戦によって数値を調整する場合は `params/` を使います。
フォルダ構成を変更するときは、HTMLと `sim/lib/headless.js` の読み込み先も更新してください。`node sim/run.js test` で読み込み先の整合性を確認できます。
