# バージョンの付け方

配布物・README・解析ログは `VERSION` の `MAJOR.MINOR.PATCH` を使用する。現在は **7.0.1**。

- **PATCH**（7.0.0 → 7.0.1）：不具合修正、既存AIの判断条件・手順・評価の調整。対戦回数を増やすだけでは変更しない。
- **MINOR**（7.0.x → 7.1.0）：新デッキへの対応、新しい探索・学習機能など、既存用途を維持する機能追加。
- **MAJOR**（7.x → 8.0.0）：ログ形式・連携APIなどの互換性を壊す変更、既存用途を置き換える大きな構成変更。

過去の「v6」は6.0.0、「v7」は7.0.0として扱う。履歴のファイル名や比較データは書き換えず、以後の配布から3桁表記を使う。今回は7.0.0を基準にしたレックウザの修正なので7.0.1とした。修正の大きさを試合数や作業回数で決めない。

`node sim/tools/update_build.js` はVERSIONを検査し、`debug/build_info.js` の `version` に埋め込む。解析ログには `meta.build.version` が入る。従来の `id` はソースの指紋であり、リリース番号の代用ではない。

公開前は、VERSION・README・変更記録・配布ZIP名を一致させてから、ソース指紋を更新しテストする。
