# 資料の索引

| ファイル | 内容 |
|---|---|
| `CHANGELOG.md` | 版ごとの変更点と評価結果（新しい版が上）。ゾロアークAIのv1〜v6、対抗AIの7.0.0〜も含む |
| `DEVELOPMENT.md` | 開発・検証の手引き：コマンド、相互強化の進め方、バージョンの付け方、対戦記録の保存と再現、Windowsでの準備 |
| `AI_ARCHITECTURE.md` | 共通AI（ドラパルト・メガレックウザ）の設計と過去の実験の詳細 |
| `ai_handoff.json` | 次にAIを改良する担当者（AI）向けの要約。現在の版、変更したファイル、評価条件と結果 |

評価の数値は `../sim/results/summary.json` にまとめています。
