# Windows での準備と、PCの速さの測定

## 1. Node.js を入れる（最初の1回だけ）

**方法A（かんたん・おすすめ）**
1. ブラウザで https://nodejs.org を開く
2. 緑の「LTS」（推奨版）をダウンロードして、インストーラーを実行（設定は全部「Next」のままでOK）
3. **PowerShell を一度閉じて、開き直す**（これをしないと認識されません）
4. `node -v` と入力 → `v22.x.x` のように表示されれば成功

**方法B（コマンドで入れる）**
PowerShell で次を実行 → 終わったら PowerShell を開き直す
```
winget install OpenJS.NodeJS.LTS
```

## 2. ファイルを置く
`pokeca_cpu_ai.zip` を、**フォルダ名に空白や日本語を含まない場所**に展開します。例：`C:\pokeca\`
（例として `C:\pokeca\pokeca_cpu_ai\` の中に `index.html`、`ai`、`sim` が並ぶ形）

※ ユーザー名に空白がある（`C:\Users\kotani masato\...`）場所は、コマンドの入力が面倒なので避けるのがおすすめです。

## 3. PCの速さを測る（1〜2分）
PowerShell で：
```
cd C:\pokeca\pokeca_cpu_ai
node sim\bench.js
```
「=== このPCの情報 ===」から最後までの表示を、**そのままコピーして Claude に送ってください**。
（電源アダプタをつないだ状態で測ってください）

## 4. 長時間の自己対戦（まだ回さなくて大丈夫です）
測定結果を見てから、回す内容を決めます。準備だけ書いておきます。
```
node sim\parallel.js --procs 5 --hours 8 --games 100 --search 2 --outdir runs\data1
```
- 途中で止めるときは `Ctrl + C`。同じコマンドをもう一度打てば、続きから再開します。
- 回している間は、電源をつなぎ、スリープしない設定にしてください（設定 → システム → 電源）。
- ノートPCは熱で遅くなるので、`--procs` は最初は 3〜4 くらいにして様子を見てください。
- 集まったデータで学習：`node sim\train_all.js runs\data1`（`ai\value_model.js` が更新されます。元のファイルは先にコピーで保存しておいてください）

※ 現在の価値関数は、データを増やしても精度が伸びない段階です（前回の実験で確認）。長時間回すのは、次の段階（カードの中身を見られる価値関数）を私が作ってからにしましょう。
